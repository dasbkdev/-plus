### 3.1 Возведение числа в степень

Условие задачи. Написать функцию double power(double N, int P = 2). При отсутствии показателя вычислять квадрат; вводимый вручную показатель должен быть больше 2. Прототип разместить перед main. Диалог с пользователем повторять в цикле while.

Данные программы. N — основание, P — показатель, choice — выбор ввода степени, repeat — ответ о повторении расчета.

Проверки и ограничения. При P <= 2 программа выводит ошибку и завершается. Для вычислений вводятся корректные числа, результат которых представим типом double. Функция power использует исходный цикл for.

#### 3.1.1 Алгоритм

1. Установить repeat = y. Пока ответ равен y или Y, повторять диалог.

2. Ввести N и choice. При ответе y или Y ввести P > 2.

3. Вызвать power(N, P) или power(N) с показателем 2 по умолчанию.

4. В power установить result = 1.0 и P раз выполнить result *= N в цикле for.

5. Вывести результат, запросить repeat. При другом ответе завершить работу.

#### 3.1.2 Блок-схема

#### Блок-схема функции power

#### 3.1.3 Программный код

```cpp
#include <iostream>
using namespace std;

double power(double N, int P = 2);

int main() {
    double N;
    char choice;

    char repeat = 'y';
    // Повторяем расчёт, пока пользователь отвечает y.
    while (repeat == 'y' || repeat == 'Y') {
        cout << "Введите число N: ";
        cin >> N;

        cout << "Хотите ввести степень P? (y/n): ";
        cin >> choice;

        if (choice == 'y' || choice == 'Y') {
            int P;
            cout << "Введите степень P: ";
            cin >> P;

            if (P <= 2) {
                cout << "Ошибка: степень должна быть больше !" << endl;
                return 1;
            }

            cout << "Результат: " << power(N, P) << endl;
        } else {
            cout << "Результат (в квадрате по умолчанию): " << power(N) << endl;
        }

        cout << "Повторить расчёт? (y/n): ";
        cin >> repeat;
        if (!cin) break;
    }

    return 0;
}

double power(double N, int P) {
    double result = 1.0;

    for (int i = 0; i < P; i++) {
        result *= N;
    }

    return result;
}
```

### 3.3 Работники заводов

Условие задачи. Описать структуру работника с фамилией, возрастом, специальностью и средним окладом. Ввести сведения о работниках N заводов и посчитать общее число слесарей и токарей.

Данные программы. Worker хранит surname, age, specialty и salary. Factory хранит name и vector<Worker> workers. Вектор factories содержит все заводы.

Проверки и ограничения. Количество заводов и работников задается неотрицательными целыми числами. Названия, фамилии и специальности вводятся одним словом. Учитываются записи слесарь/Слесарь и токарь/Токарь.

#### 3.3.1 Алгоритм

1. Ввести число заводов и создать vector<Factory> factories.

2. Для каждого завода ввести название и число работников.

3. Во вложенном цикле прочитать структуру Worker и добавить ее в workers методом push_back.

4. Обнулить locksmithCount и turnerCount. Перебрать всех работников и подсчитать нужные специальности.

5. Вывести количество слесарей и токарей по всем заводам.

#### 3.3.2 Блок-схема

#### 3.3.3 Программный код

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

struct Worker {
    string surname;
    int age;
    string specialty;
    double salary;
};


struct Factory {    
    string name;
    vector<Worker> workers;
};

int main() {
    int numFactories;
    cout << "Введите количество заводов N: ";
    cin >> numFactories;

    // Создаем вектор из N заводов
    vector<Factory> factories(numFactories);

    // Внешний цикл: проходим по каждому заводу из N
    for (int i = 0; i < numFactories; i++) {
        cout << "\n--- Завод #" << i + 1 << " ---" << endl;
        cout << "Название завода: ";
        cin >> factories[i].name;

        int numWorkers;
        cout << "Введите количество работников на заводе: ";
        cin >> numWorkers;

        // Внутренний цикл: заполняем данные каждого работника текущего завода
        for (int j = 0; j < numWorkers; j++) {
            Worker w; // Временный объект работника
            cout << "\nРаботник #" << j + 1 << ":" << endl;
            cout << "  Фамилия: ";
            cin >> w.surname;
            cout << "  Возраст: ";
            cin >> w.age;
            cout << "  Специальность (например: слесарь, токарь, инженер): ";
            cin >> w.specialty;
            cout << "  Средний оклад: ";
            cin >> w.salary;

            // Добавляем заполненного работника в вектор работников текущего завода
            factories[i].workers.push_back(w);
        }
    }

    int locksmithCount = 0; // Счетчик слесарей
    int turnerCount = 0;    // Счетчик токарей

    // Внешний цикл: обходим все заводы
    for (int i = 0; i < numFactories; i++) {
        // Внутренний цикл (range-based for): обходим каждого работника текущего завода
        for (const auto& worker : factories[i].workers) {
            // Проверяем специальность работника (с учетом регистра первой буквы)
            if (worker.specialty == "слесарь" || worker.specialty == "Слесарь") {
                locksmithCount++; // Инкрементируем счетчик слесарей
            } else if (worker.specialty == "токарь" || worker.specialty == "Токарь") {
                turnerCount++; // Инкрементируем счетчик токарей
            }
        }
    }

    // Вывод итоговых подсчетов
    cout << "\n================ РЕЗУЛЬТАТЫ ================" << endl;
    cout << "Всего слесарей по всем заводам: " << locksmithCount << endl;
    cout << "Всего токарей по всем заводам: " << turnerCount << endl;

    return 0;
}
```
