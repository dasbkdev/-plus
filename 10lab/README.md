# Лабораторная работа № 10. Исключения

Каждый taskN.cpp — отдельная программа. Общие проверки ввода находятся в ../common/input.h.
Компиляция из этой папки в WSL/Linux:

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic task1.cpp -o task1
./task1
```

Для другой задачи замените task1 на task2 или task3. Числа вводятся по одному на строку,
дробная часть — через точку. Программа объясняет ошибку и повторяет ввод. 0 в главном меню
завершает работу. EOF (Ctrl+D в WSL) также завершает программу.

Учтены задания основной методички и корректировки 2026 года по теме, а не по ошибочно
сдвинутым номерам. Отчет содержит условия, алгоритмы, код, результаты проверок и ответы
на все вопросы к защите.

Неверный индекс, неположительная сторона и выход за емкость стека вызывают показанные в меню исключения. После catch программа продолжает работу. Задача 3 добавлена из корректировки темы «Исключения».
