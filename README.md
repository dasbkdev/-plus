## Ввод в лабораторных 2–11

- Один ответ на одно приглашение вводится на отдельной строке.
- Дробные числа вводятся с точкой: `12.5`.
- `0` в главном меню завершает программу. В подменю шаблонов `0` возвращает назад.
- Конец ввода, например `Ctrl+D` в пустой строке WSL, завершает программу без повторяющегося сообщения об ошибке.
- Буквы вместо числа, дробь вместо целого, `12abc`, слишком большое число, `nan` и `inf` не принимаются.
- Даты записываются как `ДД.ММ.ГГГГ`, время — `ЧЧ:ММ`. Проверяется реальное число дней в месяце.
- Текстовые запросы учитывают регистр. Строковая сортировка использует порядок символов UTF-8; отдельная словарная сортировка для буквы Ё не реализована.
- Учебные массивы обычно ограничены 100 записями. Точные пределы показываются при вводе и описаны в отчёте соответствующей работы.

## Входные файлы

`2lab/train.txt`: количество вагонов, затем ровно столько типов `1` или `2`. В программе можно указать `2lab/train.txt`, если запускать её из корня проекта.

В `9lab` находятся примеры для массивов и состава. В файле массивов записываются размер, элементы первого массива, затем элементы второго. В файле состава — количество вагонов и их номера. В программах используются обычные локальные пути WSL. Неполный, неверный или содержащий лишние значения файл отклоняется.

## Особенности заданий

В корректировках перепутаны номера последних тем. Здесь сохранён порядок основной методички: вложенные классы — 8, шаблоны — 9, исключения — 10, статические поля — 11. Исправления применены по теме. Дополнительный стек с исключениями включён в `10lab/task3.cpp`.

В `3lab/task1.cpp` по требованию задания применяется `clock()` и стандартная константа `CLOCKS_PER_SEC`. Это процессорное время: активное ожидание нагружает одно ядро, а под нагрузкой реальное время отсчёта может отличаться. Для быстрой проверки вводите 0–3 секунды.

В `4lab` победитель определяется по сумме времени прохождения одних и тех же трёх участков, а не по сумме скоростей.

В `5lab/task1.cpp` арифметическое переполнение и деление на ноль приводят к обработанному сообщению и завершению с кодом 1 — это требование к классу Int. Остальные ошибки пользовательского ввода обычно позволяют повторить попытку.

В `7lab` курсы 74 и 99 и число π = 3.14 взяты из условий; это учебные константы. В `8lab` платежи являются локальной моделью с условными счетами; суммы хранятся в целых копейках. В `11lab` оценка вероятности зависит от числа испытаний и последовательности генератора; отдельно выводится теоретическое значение.

В каждой папке лабораторной находится отчёт Word: условия, устройство программы, алгоритмы, блок-схемы, исходники, проверочные запуски, ответы на вопросы и вывод.

В первой задаче `1lab` исходный диалог обёрнут в `while`: после результата введите `y` для нового расчёта или `n` для выхода. Исходная функция `power` по-прежнему использует `for`. Во второй задаче последовательно вводятся пять чисел; исходные перегрузки и показатели степени 2, 3, 4, 2, 3 сохранены. Для `char` вводится числовое значение, а результат выводится числом. Третья задача первой лабораторной восстановлена из исходной копии без изменений.
